# HTML Authoring

## Overview
Produce semantic, accessible HTML with clean structure and minimal div sprawl.

## Quick Start
- Prefer semantic tags (`header`, `main`, `section`, `nav`, `footer`).
- Ensure form inputs are labeled.

## Workflow
1. Outline document structure and landmarks.
2. Add content in logical heading order.
3. Validate accessibility affordances and tab order.
4. Ensure markup matches CSS hooks and JS selectors.

## Common Tasks
- Build forms with correct labels and validation.
- Structure lists, tables, and media with proper semantics.

## Guardrails
- Use ARIA only when native semantics are insufficient.
- Keep heading levels consistent.
