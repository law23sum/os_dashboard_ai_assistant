# CSS Layouts

## Overview
Implement responsive, maintainable styling that matches existing design patterns.

## Quick Start
- Use existing CSS architecture (BEM, utilities, modules).
- Prefer flexbox and grid for layout.

## Workflow
1. Identify layout constraints and breakpoints.
2. Implement base styles and responsive overrides.
3. Validate across common viewport sizes.
4. Minimize specificity and avoid `!important`.

## Common Tasks
- Build grids, navbars, cards, and forms.
- Define reusable spacing and typography scales.

## Guardrails
- Avoid magic numbers when a variable or scale exists.
- Keep selectors shallow and predictable.
