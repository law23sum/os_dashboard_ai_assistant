# React Frontend

## Overview
Deliver React UI changes with clean components, hooks, and accessible markup.

## Quick Start
- Identify framework and build tool (Vite, Next, CRA).
- Follow existing component and styling conventions.

## Workflow
1. Locate component hierarchy and data flow.
2. Implement changes with functional components and hooks.
3. Validate state updates, effects, and memoization needs.
4. Run relevant tests and dev builds.

## Common Tasks
- Add components and hooks with clear props.
- Handle forms and validation.
- Optimize rerenders with `useMemo` and `useCallback` only when needed.

## Guardrails
- Keep components pure; avoid side effects in render.
- Ensure list keys are stable and unique.
- Maintain accessibility (labels, roles, focus).
