## 🚀 Getting Started

### Quick Start Commands
```bash
# Install dependencies
pip install -r requirements.txt

# Run tests
python -m os_dashboard_enterprise.testing.test_cli run --level smoke

# Start development server
python -m os_dashboard_enterprise.main --environment development

# Deploy to production
docker-compose -f deployment/docker-compose.prod.yml up -d
```

### Configuration
```bash
# Create configuration
python -m os_dashboard_enterprise.testing.test_cli config-create --environment production

# Validate setup
python -m os_dashboard_enterprise.testing.test_cli status

# Run full test suite
python -m os_dashboard_enterprise.testing.test_cli run --level full
```
