Installation workflow

1. Download artifacts

Grab the installer for your platform plus the license file from the customer portal.

2. Authenticate

Run osdash login or sign in through the desktop UI to link your workspace.

3. Configure connectors

Use the setup wizard to add Microsoft, Google, Slack, ServiceNow, or custom APIs.

4. Invite your team

Sync groups from Azure AD/Okta or add members manually with role-based policies.

System prep checklist

Task Details
Network Allow outbound HTTPS to api.osdash.local and hub.osdash.local.
Ports Open 443, 4222 (NATS), and 5432 (Postgres) on self-hosted deployments.
Service account Create a least-privileged identity for automation secrets.
Observability Send logs to your SIEM via syslog or the built-in Splunk integration.
