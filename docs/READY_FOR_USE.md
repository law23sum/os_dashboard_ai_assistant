   - Create prompt with tools enabled
   - Copy Prompt ID

2. **Set Environment Variables** (1 minute)
   ```bash
   npm run setup
   # Or manually create .env.local
   ```

3. **Test Setup** (1 minute)
   ```bash
   npm run test-setup
   ```

4. **Start Application** (1 minute)
   ```bash
   npm run dev
   ```
