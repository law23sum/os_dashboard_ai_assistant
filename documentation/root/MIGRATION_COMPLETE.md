## 🚀 Quick Start

### Development
```bash
cd frontend
npm install
npm run dev
# Choose: 1 for Web, 2 for Desktop
```

### Production Builds
```bash
# Web
npm run build:web

# Desktop - All platforms
npm run build:all

# Desktop - Specific platform
npm run build:desktop:linux
npm run build:desktop:windows
npm run build:desktop:mac
```
